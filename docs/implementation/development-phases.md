## Execution discipline

First land failing regressions for critical defects without connecting to configured production resources. Then repair one rule owner and exercise integration against an explicitly isolated MongoDB replica set. Model methods should validate/calculate only; sales/payment services own side effects and session propagation. External reference strings are not payment settlement verification.

For data/index changes, add versioned dry-run scripts with explicit preconditions, backup/restore evidence, duplicate/unit classification and a reviewable report. Do not delete old financial records to make uniqueness succeed. Preserve compatibility aliases until all active callers use canonical fields and envelopes. Keep source moves and unused-code removal in separate, justified changes.

## Conditional packages excluded from the base plan

Shared-store membership requires R01 approval and owner/actor migration; it cannot be replaced with shared cashier passwords. Kiosk access requires R03/R04 device/queue requirements and an independent constrained authorization boundary. Refunds/returns/discounts, purchase receiving/suppliers, ISBN-specific catalog and full accounting require their own accepted policies. They are not scaffolded or represented as completed modules.
